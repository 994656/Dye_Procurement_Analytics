# Dye Procurement Analytics

This project simulates a dye raw material procurement management system.

## Objectives

- Analyze supplier delivery performance
- Monitor inventory risks
- Improve procurement decision making

## Tools

- SQL
- Excel
- Data Analysis

## Key Analysis

1. Supplier delivery rate
2. Purchase order delay analysis
3. Inventory shortage detection
